# Dados experimentais

- `identificacao_planta_nominal.csv`: PRBS nominal herdado do PRJ1;
- `identificacao_planta_com_cooler.csv`: identificação sob convecção forçada;
- `ensaio_controle_nominal.csv`: primeira realização física do PRJ2;
- `ensaio_controle_escalonado.csv`: controlador com dois regimes;
- `ensaio_controle_refinado.csv`: ensaio final adotado no relatório.

Os arquivos são dados brutos ou consolidados de bancada e não devem ser
sobrescritos pelos scripts. Novas coletas recebem nomes datados.
